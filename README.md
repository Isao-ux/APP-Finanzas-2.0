# Órbita · Finanzas personales

App web instalable para registrar ganancias, gastos y ahorros, ver de dónde viene cada peso y cuánto queda para ocio, personal y ahorro.

## Cómo activarla
1. En este repositorio: **Settings → Pages**.
2. En *Build and deployment*, elige **Deploy from a branch**, rama **main** y carpeta **/ (root)**. Guarda.
3. En un par de minutos queda en `https://isao-ux.github.io/APP-Finanzas-2.0/`.

## Instalarla
- **Android (Chrome):** abre el link → menú ⋮ → *Instalar app*.
- **iPhone (Safari):** abre el link → botón Compartir → *Agregar a pantalla de inicio*.
- **Computador (Chrome/Edge):** ícono de instalar en la barra de direcciones.

## Tus datos
Los movimientos se guardan solo en el dispositivo donde los registras; nada se sube a GitHub.
Usa **Exportar respaldo** para guardar una copia y **Importar respaldo** para pasarla a otro dispositivo.
El usuario y el PIN de 4 dígitos protegen la app en ese dispositivo. Si olvidas el PIN, puedes crear un acceso nuevo, pero se borran los datos del dispositivo (recupéralos importando un respaldo).
